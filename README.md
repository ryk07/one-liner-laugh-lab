One short funny line answering a prompt: the excuse a robot vacuum gives after eating a sock.

> In my defence, the sock resigned from foot duty and applied to be lunch. I only processed the paperwork.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (stdlib only, no dependencies).
